I gathered the main concepts and key steps to build a functional computer through
surface level research from known creators from [YouTube](https://www.youtube.com).
Then with resources/sites (such as [pcpartpicker](https://pcpartpicker.com))
recommended by these creators, I planned out the components to get that are budget
friendly while also being powerful enough to run basic games at good frame rates
(~120-200 fps). The build runs on AMD's AM4 platform, using an AMD Ryzen 5 5500
processor for the CPU, 32 GB DDR4 ram (3200 MT/s), 1 TB SSD storage, and has the
AMD Radeon RX 6600 as the GPU.
